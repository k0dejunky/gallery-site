# The public renditions of the media ARE crawlable. The structured data
# points at them (the ImageObject's contentUrl, the video sitemap's
# content_loc), and a crawler cannot fetch a URL that robots.txt forbids -
# so the promise and the rule have to agree. The ORIGINAL still needs a
# media token, so it stays blocked here (and answers 404 without a
# session anyway).
